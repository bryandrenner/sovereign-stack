# Sovereign Stack

A sovereign stack of self-hosted FOSS services.

This project will bundle my personal services — photo backup, file sync, and other day-to-day tooling — alongside my own developed services and experiments, into a single reproducible deployment built on free and open-source software. The goal is digital autonomy: owning my data, my services, and my infrastructure choices.

**Principles:**

- **FOSS first** — services and infrastructure are built on free and open-source software wherever possible.
- **Self-hosted** — everything runs on infrastructure I administer, with my data under my control.
- **Provider-portable** — the infrastructure layer is swappable by design, so the stack can move between hosting providers. Hetzner is the current target.
- **Independent at runtime** — the deployed stack runs without Big Tech services.
